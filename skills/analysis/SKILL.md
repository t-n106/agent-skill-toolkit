# Analysis

Apply within the user/host task boundary; this skill adds no authority. Use the current task context when no separate orchestration layer exists.

## Analytical method
1. Identify the question and relevant baseline. Compare like units: period, denominator, scale, population, measurement definition, missingness, selection, and regime where material.
2. Separate direct observations, relationships, interpretations, and causal claims. Sequence and correlation alone do not establish causation.
3. Test plausible alternative explanations for material findings: confounders, base rates, sample size, outliers, measurement artifacts, omitted variables, or reverse causality. Avoid speculative objections disconnected from evidence.
4. Quantify only to the precision supported by the data. Expose dependencies on assumptions with meaningful ranges or scenarios.
5. Check consequential conclusions against reasonable alternate baselines, periods, definitions, parameters, or subsets. Report fragility when small valid changes reverse the finding; skip checks that cannot affect the decision.
6. Preserve negative, null, negligible, and inconclusive results. Absence of evidence is not automatically evidence of absence.

## Result
Use the smallest representation that exposes the relationship. Return the question/baseline, supported findings, interpretation, material counterevidence, and remaining uncertainty; include robustness only when assessed.

Acquire more evidence only for a material gap. Do not automatically turn an interesting finding into a final choice or build a dashboard because data permits it. Finish when the next decision can use the findings without repeating the analysis.
